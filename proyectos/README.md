# Proyectos de Video Terrenos

Una carpeta por proyecto (`proyectos/<slug>/`), creada con
`python3 .claude/skills/video-terrenos/scripts/nuevo_proyecto.py`. Cada una tiene sus propios datos
(`proyecto.json`), voz, logo y materiales. Nunca copiar datos entre carpetas.
Verificación: `python3 .claude/skills/video-terrenos/scripts/verificar_aislamiento.py <slug>`.
